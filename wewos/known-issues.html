Known issues

What is known to be missing or to behave differently.

In the page

  • Grab Image needs the page. A viewer's picture is drawn by the browser, so Grab Image (and the nodes after it) can only run while a page shows the network, with the viewer panel open. Run without a page (bin/wewos run), it fails after 15 seconds.
  • Mol*'s own panels. What you add in Mol*'s panels (representations, measurements) is not saved, and the network's next change redraws the scene.
  • Copy and paste work within a network, not from one network to another.
  • Widget options: only number widgets have an options dialog (minimum, maximum, step, one turn, precision).

Importing Vision networks

  • Changes inside a library macro (nodes or connections added in it) are not carried over; the macro is the library's. The import report lists them. The tutorial's mol2plv_net.py is an example: it added a translation inside Icosahedral1.
  • A port that a Vision library macro gained for a geometry's parent (e.g. Lines Macro's IndexedPolylines_parent) has no counterpart; its connection is reported as not made.
  • Nodes of libraries that are not ported (PMV, ADT, web services…) are placeholders that do not run.
  • Widget values given by port number, rather than by name, are not imported.

Not ported

User panels; saving a node to a user library from its menu; DejaVu's textures (ImageFigure), volume rendering, clip planes and stereo; QSlim; matplotlib's navigation toolbar. See WEWoS and Vision.
