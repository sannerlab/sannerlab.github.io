# Sanner Lab website

Served at **https://sannerlab.github.io**. Built with
[Lab Website Template](https://greene-lab.gitbook.io/lab-website-template-docs) (BSD-3, see `LICENSE.md`).

- `_data/sources.yaml` — publications by DOI; GitHub Actions fill in the details
- `_data/orcid.yaml` — optional, to pull publications from ORCID: create it as a list, e.g. `- orcid: 0000-0000-0000-0000` (a file with only comments fails the build)
- `_data/projects.yaml` — the Tools page
- `_members/` — one file per team member
- `adapt/` — **test copy** of ADapt's rendered docs (HTML + screenshots only, no code).
  Not auto-updated; long term, each tool repo should publish its own docs.
