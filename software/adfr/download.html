Download ADFRsuite

ADFR is distributed as part of the ADFR software suite (ADFRsuite), which contains everything needed to set up docking experiments for small molecules and peptides.

ADFRsuite 1.0 rc1

Release candidate 1 of ADFRsuite 1.0 contains:

  • ADFR 1.2 and associated scripts
  • AGFR 1.2
  • AutoSite 1.0 and 1.1
  • ADCP 1.0
  • AutoGrid 4.2
  • prepare_ligand
  • prepare_receptor

Installation notes

  • The commercial installation does not install MSMS, the component that computes molecular surfaces. For a commercial MSMS license contact Dr. Michel Sanner. All other tools in the suite work fully in both installations.
  • The default install location is ~/ADFRsuite-1.0. If your home folder is not on a local disk, install to a folder on a local disk for better performance.
  • ADFRsuite ships its own Python interpreter (2.7), installed in the ADFRsuite-1.0 folder. It is isolated from your system Python and does not interfere with it. Start it with ADFRsuite-1.0/bin/pythonsh.

Installing from a tarball

This example uses the macOS tarball; for another tarball change the file and folder names.

# unpack the tar file
tar zxvf ADFRsuite_x86_64Darwin_1.0.tar.gz

# step into the folder created by unpacking
cd ADFRsuite_x86_64Darwin_1.0

# run the installation script
#   -d destinationFolder  where to install ADFRsuite 1.0
#   -c                    how to compile the Python files: 0 for .pyc, 1 for .pyo
./install.sh -d myFolder -c 0

Known issues

Linux 64-bit with older versions of GCC:

ImportError: /usr/lib64/libstdc++.so.6: version `GLIBCXX_3.4.15' not found (required by ADFRsuite-1.1/lib/python2.7/site-packages/_openbabel.so)

To fix the error:

cd <InstallationDir>/ADFRsuite-1.0/lib
mv libstdc++.so.6.orig libstdc++.so.6

ADFRsuite 1.1 (development version)

A development build of ADFRsuite 1.1 is available for Linux 64-bit: ADFRsuite_Linux-x86_64_1.1dev_Install (SourceForge). Install it like the 1.0 installer app:

chmod a+x ADFRsuite_Linux-x86_64_1.1dev_Install
./ADFRsuite_Linux-x86_64_1.1dev_Install
