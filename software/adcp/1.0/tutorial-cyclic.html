Tutorial: re-docking a cyclic peptide

WarningYou are viewing ADCP 1.0 (deprecated)

These pages describe version 1.0, distributed with ADFRsuite 1.0. For new work use ADCP 1.1.

This tutorial re-docks a cyclic peptide with a disulfide bond into its native receptor: a 10-mer peptide from EBV into HLA-A*11:01 (PDB 5GRD).

You will learn to:

  • generate a target file for docking in a box defined by the known peptide
  • run ADCP to re-dock a cyclic peptide
  • understand the output of an ADCP docking run

Prerequisites: ADFRsuite 1.0 installed with ADFRsuite-1.0/bin on your PATH, and the tutorial data downloaded (see Tutorials).

1. Generate the target file

Go to the directory for this tutorial:

cd ADCP_tutorial_data/5GRD

This tutorial starts from PDBQT files. See the first tutorial for converting PDB files to PDBQT.

agfr -r 5GRD_recH.pdbqt -l 5GRD_pepH.pdbqt -o 5GRD

2. Dock the cyclic peptide

adcp -t 5GRD.trg -s sscsscplsk -N 20 -n 500000 -cys -o 5GRD_redocking -ref 5GRD_pepH.pdbqt -nc 0.8

Two options are added compared with the linear peptide:

Option Meaning
-cys enables the potential for disulfide bonds
-nc 0.8 clusters by native contacts; recommended for larger peptides

Important

Docking cyclic peptides is very hard. This tutorial only shows how to use ADCP; for production runs, use more replicas with more Monte Carlo steps.

NoteReview note (prototype only)

The example output says “20 ADCP runs with 5000000 steps each”, but the command uses -n 500000. One of the two is wrong on the CCSB page.
