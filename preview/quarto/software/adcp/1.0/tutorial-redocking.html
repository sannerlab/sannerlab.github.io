Tutorial: re-docking a 7-mer peptide

WarningYou are viewing ADCP 1.0 (deprecated)

These pages describe version 1.0, distributed with ADFRsuite 1.0. For new work use ADCP 1.1.

This tutorial re-docks a known peptide into its native receptor: a pseudophosphorylated Smad1 peptide into the TPR domain of CHIP (PDB 3Q47).

You will learn to:

  • generate a target file for docking in a box defined by the known peptide
  • run ADCP to re-dock the peptide
  • understand the output of an ADCP docking run

Prerequisites: ADFRsuite 1.0 installed with ADFRsuite-1.0/bin on your PATH, and the tutorial data downloaded (see Tutorials).

1. Convert PDB files to PDBQT files

PDBQT is the file format of the AutoDock programs. It adds two columns to the PDB format: the partial charge and the AutoDock atom type.

We start from two separate PDB files for the receptor and the peptide, split from the 3Q47 entry. Both contain only protein atoms.

Unzip the data and go to the directory for this tutorial:

unzip ADCP_tutorial_data.zip
cd ADCP_tutorial_data/3Q47

Add hydrogens to both files with reduce (included in ADFRsuite):

reduce 3Q47_rec.pdb > 3Q47_recH.pdb
reduce 3Q47_pep.pdb > 3Q47_pepH.pdb

Convert the protonated PDB files into PDBQT files with prepare_receptor and prepare_ligand:

prepare_receptor -r 3Q47_recH.pdb
prepare_ligand -l 3Q47_pepH.pdb

2. Generate the target file

A target file is a zipped file with everything needed for docking with ADFR and ADCP. It can be generated from the command line or a GUI.

agfr -r 3Q47_recH.pdbqt -l 3Q47_pepH.pdbqt -asv 1.1 -o 3Q47

This puts the docking box around the given peptide with 4 Å padding. If you do not know the peptide binding site, see the agfrgui tutorials.

Option Meaning
-r the receptor file (required)
-l the ligand file
-asv AutoSite version, 1.0 or 1.1 (default 1.0 when -asv is not given)
-o name for the target file

Details. agfr positions and sizes the docking box over the receptor pocket(s) where the ligand will be docked, and computes affinity maps for a list of AutoDock4 atom types. The maps are calculated by AutoGrid4.

  • Box. The box can be set in several ways with -b/--boxMode. Here agfr uses the bounding box of the known ligand (-l/--ligand), with 4 Å of padding added on every side. Change the padding with -P/--padding.
  • Output. The target file (.trg) is saved under the name given by -o/--output; without it, a unique descriptive name is created. It contains the affinity maps, translational points for placing the ligand at sensible positions in the box, and metadata about the grid size, position and spacing, the receptor atoms involved and the maps. Inspect it with the about command.
  • Pockets. The translational points are computed by AutoSite, which clusters high-affinity grid points into potential binding pockets. -p/--pocketMode sets how multiple clusters are handled; when it is omitted, as here, all clusters are merged into one set of translational points.
  • Atom types. By default maps are computed for all AutoDock4 atom types. Restrict them with -m/--mapTypes for smaller files and faster runs, but the target file then cannot dock ligands with atom types it has no map for.

3. Dock the peptide from its sequence

adcp -t 3Q47.trg -s npisdvd -N 20 -n 1000000 -o 3Q47_redocking -ref 3Q47_pepH.pdb

adcp detects the available cores and uses all of them by default. Here it runs 20 independent searches (-N, --nbRuns 20), each with up to 1,000,000 evaluations of the scoring function (-n, --numSteps). By default adcp runs 50 searches of 2.5 million evaluations each. Harder docking problems need more searches to raise the chance of finding the best pose (the global minimum of the scoring function).

The run writes:

File Content
3Q47_redocking_ranked_*.pdb final solutions, ranked after clustering
3Q47_redocking_*.pdb the Monte Carlo trajectory of each replica
3Q47_redocking_*.out detailed output of each replica
TipNotes
  • The search is stochastic: docking the same peptide into the same target twice can give different results with different random seeds. The energy landscape is the same in both runs; if both find its global minimum they give the same solution, whatever path the search took. Searches trapped in local minima give different poses. Setting the seed (--seed) makes a run reproducible for a given version of the code.
  • In general, run 100 replicas with 1 million steps per amino acid, starting from a mixture of extended and helical conformations.
